# AutoTrack

## Descripción

AutoTrack es un proyecto web desarrollado con Django para llevar el control de vehículos y su mantenimiento.

El sistema permite administrar información de usuarios, vehículos, mantenimientos, tipos de mantenimiento, talleres, refacciones y recordatorios.

En esta etapa del proyecto se desarrolló una API REST utilizando Django REST Framework, con el objetivo de permitir el acceso a la información del sistema mediante diferentes endpoints.

## Tecnologías utilizadas

- Python
- Django
- Django REST Framework
- SQLite
- Git
- GitHub

## Requisitos

Para ejecutar el proyecto se necesita tener instalado:

- Python 3
- Git
